# إعداد جدول wheel_spins في Supabase

## إنشاء الجدول في Supabase

1. اذهب إلى لوحة تحكم Supabase
2. اختر مشروعك
3. اذهب إلى **SQL Editor**
4. نفذ الأمر التالي:

```sql
-- إنشاء جدول wheel_spins
CREATE TABLE IF NOT EXISTS wheel_spins (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    telegram_id TEXT NOT NULL UNIQUE,
    last_spin_at TIMESTAMP WITH TIME ZONE,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- إنشاء index على telegram_id للسرعة
CREATE INDEX IF NOT EXISTS idx_wheel_spins_telegram_id ON wheel_spins(telegram_id);

-- تفعيل Row Level Security (اختياري)
ALTER TABLE wheel_spins ENABLE ROW LEVEL SECURITY;

-- سياسة للسماح بالقراءة والكتابة للجميع (يمكن تعديلها حسب الحاجة)
CREATE POLICY "Allow all operations on wheel_spins"
    ON wheel_spins FOR ALL
    USING (true)
    WITH CHECK (true);
```

## التحقق من الجدول

بعد إنشاء الجدول، يمكنك التحقق من وجوده في قسم **Table Editor** في Supabase.
