## 🚀 التثبيت والتشغيل

### المتطلبات
- Python 3.8+
- Docker & Docker Compose (للنشر الاحترافي)
- Git

### التثبيت السريع

1. **نسخ المشروع**
```bash
git clone <repository-url>
cd jado_ichancy_bot
```

2. **تثبيت الاعتماديات**
```bash
pip install -r requirements.txt
```

3. **إعداد متغيرات البيئة**
```bash
cp .env.example .env
# قم بتحرير ملف .env بإعداداتك
```

4. **تشغيل البوت**
```bash
python bot.py
```

5. **تشغيل لوحة التحكم**
```bash
python web_admin/app.py
```

### التثبيت باستخدام Docker (موصى به للإنتاج)

1. **تشغيل السكربت التلقائي**
```bash
chmod +x deployment/start.sh
./deployment/start.sh
```

2. **أو يدوياً**
```bash
docker-compose -f deployment/docker-compose.yml up -d
```

## 🔧 الإعدادات

### ملف .env
```env
# إعدادات البوت
BOT_TOKEN=YOUR_BOT_TOKEN_HERE
COOKIE_STRING=YOUR_COOKIE_STRING_HERE
ADMIN_TELEGRAM_ID=YOUR_ADMIN_ID_HERE

# إعدادات لوحة التحكم
SECRET_KEY=your-secret-key-here-change-in-production

# إعدادات قاعدة البيانات
DB_PATH=./database.db
```

### الوصول إلى لوحة التحكم
- الرابط: `http://localhost:8080`
- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

**مهم:** قم بتغيير كلمة المرور الافتراضية فوراً!

## 🔄 التكامل مع البوت

تم دمج لوحة التحكم بالكامل مع البوت من خلال:

### الإشعارات الفورية
```python
from bot_integration import on_user_registered, on_transaction_created

# عند تسجيل مستخدم جديد
on_user_registered(user_data)

# عند إنشاء معاملة جديدة
on_transaction_created(transaction_data)
```

### تحديثات الوقت الفعلي
- WebSocket للاتصال الفوري
- تحديث تلقائي للبيانات
- إشعارات فورية بدون تحديث

## 📊 API

توفر لوحة التحكم REST API كامل للتحكم البرمجي:

### نقاط النهاية الرئيسية
- `GET /api/users` - قائمة المستخدمين
- `POST /api/users/{id}/balance/update` - تحديث الرصيد
- `GET /api/transactions` - قائمة المعاملات
- `POST /api/transactions/{id}/approve` - موافقة على معاملة
- `POST /api/exchange_rate/update` - تحديث سعر الصرف
- `GET /api/system/info` - معلومات النظام

### المصادقة
جميع طلبات API تتطلب تسجيل دخول الأدمن.

## 🛠️ الصيانة

### النسخ الاحتياطي
```bash
# نسخ احتياطي تلقائي
docker-compose exec bot python backup.py

# نسخ احتياطي يدوي
cp database.db backups/backup_$(date +%Y%m%d_%H%M%S).db
```

### عرض السجلات
```bash
# سجلات البوت
docker-compose logs -f bot

# سجلات لوحة التحكم
docker-compose logs -f admin_panel
```

### إعادة التشغيل
```bash
# إعادة تشغيل جميع الخدمات
docker-compose restart

# إعادة تشغيل خدمة معينة
docker-compose restart bot
docker-compose restart admin_panel
```

## 🔧 التطوير

### إضافة ميزات جديدة
1. إضافة مسارات جديدة في `web_admin/app.py`
2. إنشاء قوالب HTML في `web_admin/templates/`
3. إضافة نقاط نهاية API في `web_admin/api.py`
4. تحديث الأنماط في `web_admin/static/css/`

### هيكل المشروع
```
jado_ichancy_bot/
├── bot.py                 # الملف الرئيسي للبوت
├── web_admin/            # لوحة التحكم
│   ├── app.py           # تطبيق Flask
│   ├── api.py           # REST API
│   ├── templates/       # قوالب HTML
│   └── static/         # ملفات ثابتة
├── handlers/            # معالجات البوت
├── services/            # خدمات خارجية
├── store.py            # قاعدة البيانات
├── deployment/         # ملفات النشر
└── requirements.txt    # الاعتماديات
```

## 🚨 استكشاف الأخطاء

### مشاكل شائعة

1. **البوت لا يعمل**
   - تحقق من التوكن في ملف .env
   - تأكد من اتصال الإنترنت
   - تحقق من سجلات الأخطاء

2. **لوحة التحكم لا تعمل**
   - تحقق من المنفذ 5000
   - تأكد من تثبيت جميع الاعتماديات
   - تحقق من مفتاح SECRET_KEY

3. **مشاكل قاعدة البيانات**
   - تأكد من وجود ملف database.db
   - تحقق من الصلاحيات
   - جرب إعادة بناء الجداول

### الحصول على المساعدة
- تحقق من السجلات: `docker-compose logs`
- قم بزيارة وثائق API: `http://localhost:8080/api/docs`
- راجع قسم المشاكل الشائعة
